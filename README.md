# CalendarShouter

Display intrusive, non-overlookable alerts when your calendar events, reminders, or Canvas assignment deadlines are reaching. Made for and made by ADHD person.

## Installation

First-time installation:

```sh
brew tap balthild/tap
brew trust balthild/tap
brew install --cask calendar-shouter
```

Upgrade:

```sh
brew upgrade --cask calendar-shouter
```

## AI Usage Disclosure

This project is semi-vibe-coded. I let LLM agents to do most the coding work. However, I fully understood all the code and reviewed all the changes they made. I fine-tuned the UI/UX design manually. I also urged agents to structure the code in a way that is clear and maintainable to humans, with my own software engineering experiences.
